# 校易问用户权限

## 1. 问答与资料访问

| 操作 | 未登录用户 | 已登录学生 |
|---|---|---|
| 提问并阅读回答 | 允许 | 允许 |
| 查看引用片段 | 不允许 | 允许 |
| 在线预览完整学生手册 | 不允许 | 允许 |
| 下载完整学生手册 | 不允许 | 允许 |

## 2. 访问边界

- 未登录用户可以通过问答了解学生手册中的规定，回答可以转述相关制度内容。
- 未登录用户不能查看引用原文片段，也不能预览或下载完整手册。
- 已登录学生可以查看引用片段，并预览和下载完整手册。
- 仅上传人工转换 MD 的手册，向用户标注“转换版，未保存原文件”；已登录学生可预览、下载该 MD，系统不提供未上传原 PDF 的预览和下载。
- 问答仍遵循 `requirements.md`：仅基于已发布的学生手册回答，没有相关依据时明确说明。
- 原文引用的展示和访问受本文件约束：未登录用户不能获取引用片段，已登录学生可以查看。

## 3. 学生账号与身份验证

- 仅预置在校学生名单中的学生可以激活学生账号。
- 学生使用学号及固定格式的初始密码进行注册激活，不强制修改初始密码。
- 学生可以修改初始密码；提交留言和附件要求用户已登录且已完成改密。
- 激活时需要验证该学生在预置名单中已绑定的校园邮箱，不能通过自行填写任意邮箱替代。
- 本项目仅演示学生名单及校园邮箱验证流程，不接入真实学校身份系统。
- 初始密码的具体格式、邮箱验证的演示方式尚未确定。

## 4. 管理员与授权

- 系统部署时，由技术人员设置最高权限管理员账号，不以局域网 IP 决定身份或权限。
- 管理员身份由学校教务工作人员办理，学生不能自行注册管理员身份。
- 最高权限管理员可以分配不同管理员的操作权限。
- 普通管理员只能执行明确授予的操作，不因具有管理员身份而自动拥有全部权限。

| 管理操作 | 权限规则 |
|---|---|
| 上传手册、校验内容 | 具有相应职责和权限的管理员可执行 |
| 修改名称、版本等信息 | 具有手册信息修改权限的管理员可执行 |
| 发布手册 | 具有发布权限的管理员可执行 |
| 停用手册 | 具有停用权限的管理员可执行 |
| 逻辑删除手册 | 具有逻辑删除权限的管理员可执行 |
| 彻底删除手册 | 仅最高权限管理员可执行 |
| 禁用学生账号 | 具有账号管理权限的管理员可执行 |
| 设置匿名提问额度 | 具有额度配置权限的管理员可执行 |
| 分配管理员权限 | 最高权限管理员可执行 |
| 查看留言和附件、选择回复留言 | 所有管理员可执行 |

## 5. 手册状态与访问

- 未发布手册不作为学生问答依据。
- 停用后，手册不参与问答，学生不能预览或下载，也不能通过引用访问其原文。
- 逻辑删除后，手册不参与问答且停止学生访问；原文件保留后台，以便溯源，保留相关审计记录。
- 仅上传新版不会影响旧版。新版发布成功后，旧版停止参与问答及学生访问，保留后台。
- 留存旧版未来可以由最高权限管理员手动彻底删除。
- 彻底删除涉及原文件、索引、引用及历史记录的具体处理方式尚未确定。

## 6. 会话隐私与反馈

- 管理员不能直接查看用户的完整问答记录。
- 仅已登录且修改过初始密码的用户可以提交留言和附件。
- 用户可以主动通过留言或附件向管理员提供需要查看的内容。
- 所有管理员可以查看上述提交内容，不因此取得该用户其他会话的访问权限。
- 所有管理员均可以选择回复留言，不要求必须回复。
- 面向用户的回复仅该留言提交者可以查看，其他学生和未登录用户不能查看。
- 留言附件支持 MD、TXT、DOCX、PDF，每条留言最多 3 个，每个不超过 10 MB。
- 每名用户每天最多成功提交 3 次留言，按北京时间（Asia/Shanghai）每日零点重置；失败提交不计数。
- 登录限制和每日额度不能单独防止大量请求；请求频率等技术防护细节待后续设计。
- 留言、附件及回复的功能需求与验收条件见 `requirements.md` 中 REQ-005、REQ-006。

## 7. 禁用账号

- 具有账号管理权限的管理员可以禁用学生账号。
- 禁用后禁止登录，并立即终止已有登录状态。
- 被禁用账号的使用者仍可以按未登录用户规则提问，不拥有登录用户的资料访问和反馈提交权限。

## 8. 匿名提问限制

- 未登录用户可以提问并阅读概括性回答，不能查看引用片段、预览或下载完整手册。
- 未登录用户要求逐字输出规定或分段输出整本手册时，拒绝原文输出，仅提供概括性回答。
- 匿名提问按 IP 每日计数，额度由具有额度配置权限的管理员设置。
- 同一出口 IP 下的用户共用匿名额度。
- 默认额度、每日重置时区及可信客户端 IP 的获取方式尚未确定。

## 9. 管理操作审计

- 记录上传、校验、修改、发布、停用、逻辑删除、彻底删除、授权、账号禁用及额度配置等管理操作。
- 审计记录的字段、保留期限和查看权限尚未确定。

## 10. 尚未确定的规则

除上述明确标注的待定项外，角色组合、权限撤回后的历史会话展示及其他未明确规则均需后续确定，不视为已经授予权限。
